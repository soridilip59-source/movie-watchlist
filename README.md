# CineFamily - Full-Stack Family Movie Watchlist Application

CineFamily is a full-stack web application designed for families to curate, manage, and enjoy a shared movie watchlist together. It features secure JWT authentication, role-based access control (`parent` vs `child`), multi-member family workspaces, movie search/filters/pagination, watch status tracking, movie ratings and reviews, family dashboard statistics, and personalized movie recommendations.

---

## Tech Stack

### Frontend
- **Framework**: React.js 18 (Vite)
- **Routing**: React Router v6
- **Styling**: Vanilla CSS3 with obsidian dark theme, glassmorphic UI, responsive layout, and theme toggling
- **Icons**: Lucide React
- **HTTP Client**: Axios with request/response interceptors

### Backend
- **Runtime**: Node.js & Express.js (REST API)
- **Authentication**: JWT (JSON Web Tokens) with 30-day expiry
- **Security**: bcrypt password hashing, CORS configuration, input validation, MongoDB injection defense
- **Database**: MongoDB with Mongoose ORM (plus automatic `mongodb-memory-server` fallback for zero-config out-of-the-box local testing)

## Getting Started & Local Setup

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### 1. Backend Setup

Navigate to the `backend` folder:
```bash
cd backend
npm install
```

Create a `.env` file (or copy `.env.example`):
```env
PORT=5000
MONGODB_URI=mongodb://127.0.0.1:27017/family_watchlist
JWT_SECRET=super_secret_jwt_key_family_watchlist_2026
CLIENT_URL=http://localhost:5173
```

> **Note on MongoDB**: If you don't have a local MongoDB server running, the backend automatically starts an in-memory MongoDB database fallback (`mongodb-memory-server`) so the app works out of the box with zero external dependencies!

#### Seed Sample Data
Populate the database with realistic sample users, family workspace, 12 movies, watchlist items, and reviews:
```bash
npm run seed
```

**Sample Login Credentials generated by seed**:
- **Parent Account**: `parent@example.com` / `password123`
- **Child Account**: `child@example.com` / `password123`

#### Start Backend Server
```bash
npm run dev
# Server will start on http://localhost:5000
```

#### Run Automated Integration Tests
Verify all 12 backend API endpoints and authorization rules:
```bash
npm test
```

## Role-Based Access Control (RBAC) Matrix

| Feature / Endpoint | Parent | Child | Public |
| :--- | :---: | :---: | :---: |
| Browse Movies & Details | ✅ | ✅ | ✅ |
| Register & Login | ✅ | ✅ | ✅ |
| Add Movie to Family Watchlist | ✅ | ✅ | ❌ |
| Update Watch Status (`planned` → `watching` → `watched`) | ✅ | ✅ | ❌ |
| Rate Movies & Write Reviews | ✅ | ✅ | ❌ |
| View Family Dashboard & Recommendations | ✅ | ✅ | ❌ |
| Add Family Members | ✅ | ❌ (Forbidden 403) | ❌ |
| Remove Family Members | ✅ | ❌ (Forbidden 403) | ❌ |
| Add New Movie to Catalog | ✅ | ❌ (Forbidden 403) | ❌ |
| Edit / Delete Movies in Catalog | ✅ | ❌ (Forbidden 403) | ❌ |

## API Endpoint Documentation

### 1. Authentication APIs

#### `POST /api/auth/register`
- **Auth Required**: No
- **Request Body**:
  ```json
  {
    "name": "John Doe",
    "email": "parent@example.com",
    "password": "password123",
    "role": "parent"
  }
  ```
- **Response (201 Created)**:
  ```json
  {
    "success": true,
    "message": "Registration successful",
    "token": "eyJhbGciOi...",
    "user": {
      "_id": "60d21b4667d0d8992e610c85",
      "name": "John Doe",
      "email": "parent@example.com",
      "role": "parent",
      "avatar": "https://api.dicebear.com/7.x/avataaars/svg?seed=JohnDoe"
    }
  }
  ```

#### `POST /api/auth/login`
- **Auth Required**: No
- **Request Body**:
  ```json
  {
    "email": "parent@example.com",
    "password": "password123"
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "token": "eyJhbGciOi...",
    "user": { ... }
  }
  ```

#### `GET /api/auth/me`
- **Auth Required**: Yes (`Bearer <token>`)
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "data": {
      "_id": "60d21b4667d0d8992e610c85",
      "name": "John Doe",
      "email": "parent@example.com",
      "role": "parent",
      "familyId": "60d21b4667d0d8992e610c86"
    }
  }
  ```

---

### 2. Family APIs

#### `POST /api/families`
- **Auth Required**: Yes
- **Request Body**: `{ "name": "The Doe Family" }`
- **Response (201 Created)**: Returns created family object with member populated.

#### `GET /api/families/:id`
- **Auth Required**: Yes (Must belong to family)
- **Response (200 OK)**: Returns family structure and populated members array.

#### `POST /api/families/:id/members`
- **Auth Required**: Yes (Parent role required)
- **Request Body**:
  ```json
  {
    "email": "child@example.com",
    "role": "child",
    "name": "Timmy Doe",
    "password": "password123"
  }
  ```
- **Response (200 OK)**: Adds or creates user and joins them to family workspace.

#### `DELETE /api/families/:id/members/:userId`
- **Auth Required**: Yes (Parent role required)
- **Response (200 OK)**: Removes specified member from family.

#### `GET /api/families/:id/dashboard`
- **Auth Required**: Yes
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "data": {
      "totalMovies": 12,
      "watchlistCount": 4,
      "watchedCount": 2,
      "plannedCount": 1,
      "watchingCount": 1,
      "familyMembers": 4,
      "topGenres": [{ "genre": "Animation", "count": 3 }],
      "recentlyAdded": [ ... ],
      "recentlyWatched": [ ... ]
    }
  }
  ```

#### `GET /api/families/:id/recommendations`
- **Auth Required**: Yes
- **Response (200 OK)**: Returns array of unwatched movies matching family top genres & high ratings.

---

### 3. Movie APIs

#### `GET /api/movies`
- **Auth Required**: No
- **Query Params**: `search`, `genre`, `year`, `page=1`, `limit=10`
- **Response (200 OK)**:
  ```json
  {
    "success": true,
    "movies": [ ... ],
    "page": 1,
    "limit": 10,
    "totalMovies": 12,
    "totalPages": 2
  }
  ```

#### `GET /api/movies/:id`
- **Auth Required**: No
- **Response (200 OK)**: Returns movie details object.

#### `POST /api/movies`
- **Auth Required**: Yes (Parent role required)
- **Request Body**: `title`, `description`, `genre`, `releaseYear`, `duration`, `posterUrl`, `ageRating`
- **Response (201 Created)**: Returns created movie.

---

### 4. Watchlist APIs

#### `POST /api/watchlist`
- **Auth Required**: Yes
- **Request Body**:
  ```json
  {
    "movieId": "60d21b4667d0d8992e610c90",
    "priority": "high",
    "notes": "Watch together on Sunday evening!"
  }
  ```

#### `GET /api/watchlist/:familyId`
- **Auth Required**: Yes
- **Response (200 OK)**: Returns all watchlist items for specified family.

#### `PUT /api/watchlist/:id/status`
- **Auth Required**: Yes
- **Request Body**: `{ "status": "watched" }`
- **Response (200 OK)**: Updates status to `watched`, setting `watchedBy` and `watchedAt`.

#### `DELETE /api/watchlist/:id`
- **Auth Required**: Yes
- **Response (200 OK)**: Removes movie from family watchlist.

---

### 5. Review & Rating APIs

#### `POST /api/movies/:movieId/reviews`
- **Auth Required**: Yes
- **Request Body**:
  ```json
  {
    "rating": 5,
    "comment": "Amazing movie for the whole family!"
  }
  ```
- **Response (201 Created)**: Recalculates and updates the movie's average rating automatically.

#### `GET /api/movies/:movieId/reviews`
- **Auth Required**: No
- **Response (200 OK)**: Returns list of reviews for the movie with populated user avatars and roles.
